# SpendWise – Personal Expense Tracker

SpendWise is a console-based personal finance management application developed using Core Java. It helps users track their income and expenses, manage monthly spending limits, and monitor their financial activity.

### Features
- Add and manage income and expense transactions.
- View all recorded transactions.
- Delete existing transactions.
- Set and manage monthly spending budgets.
- View financial overviews, including total income, expenses, and available balance.
- Generate monthly reports with category-wise expense breakdowns.
- Identify the highest spending category.
- Store transaction and budget records using CSV files for data persistence.

### Concepts Used
- Object-Oriented Programming (OOP)
- Encapsulation, Inheritance, Abstraction, and Polymorphism
- Java Collections Framework
- Exception Handling
- File Handling and CSV Storage
- Java Date and Time API
- Enums and BigDecimal

**Tech Stack:** Java, Core Java, CSV File Handling
